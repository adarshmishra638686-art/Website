# NexaGrow – Digital Marketing Agency Website

A modern, responsive digital marketing agency website built with vanilla HTML, CSS, and JavaScript.

## Features

- **Hero Section** – Animated headline, stats, and CTAs
- **Services** – SEO, PPC, Content, Social Media, Email Marketing, Web Development
- **About** – Team story, values, and floating badges
- **Case Studies / Results** – Real client metrics
- **Process** – 4-step workflow
- **Testimonials** – Client reviews with star ratings
- **Contact Form** – Validated contact form with success feedback
- **Footer** – Links, social icons

## Tech Stack

- HTML5 (semantic markup)
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (IntersectionObserver, form validation)
- Google Fonts (Inter)

## Running Locally

Simply open `index.html` in any modern browser — no build step required.
